Work
----

I work across four organisations. They are part of one group, and each one has its
own job.

**[Tasmanian-Cloud](https://github.com/Tasmanian-Cloud)**

An Australian-owned hosting provider in Launceston: virtual servers, S3-compatible
storage and local support. A private beta waitlist is open.

- [`figma-import`](https://github.com/Tasmanian-Cloud/figma-import): converts a Figma
  `.fig` file into a normalised JSON document tree for a website builder.
- Forks I use and contribute to along the way: `iroh-ssh`, `pai-sho`, `freighter`,
  `meteroid`, `ledger`, `cloud-detect`.

**[TWN-Systems](https://github.com/TWN-Systems)**

IT support and systems work for Australian organisations. Each engagement starts with
the problem, agrees the next change and how to verify it, and records what changed
and who owns it.

- [`vyos-benchmarking`](https://github.com/TWN-Systems/vyos-benchmarking): reproducible
  VyOS router performance benchmarking, with iperf3 methodology, Ansible playbooks and
  RFC 2544 notes.
- [`vyos-ansible`](https://github.com/TWN-Systems/vyos-ansible): Ansible for VyOS.
- [`operately-rs`](https://github.com/TWN-Systems/operately-rs): Rust bindings for
  Operately's external API, generated from an API catalogue file.
- [`sfos-rs`](https://github.com/TWN-Systems/sfos-rs): Rust.
- [`PIMPyourDocs`](https://github.com/TWN-Systems/PIMPyourDocs): practical Markdown
  documentation practices.

**[Ptyktos](https://github.com/Ptyktos)**

Turns websites, documents and videos into clean, searchable text for software and AI
tools. It also ships a few small standalone Rust tools.

- [`sdirstat`](https://github.com/Ptyktos/sdirstat): cross-platform filesystem indexer.
  [`sdirstat-desktop`](https://github.com/Ptyktos/sdirstat-desktop) is its Tauri GUI.
- [`pii-redactor`](https://github.com/Ptyktos/pii-redactor): local, on-device PII and
  secrets redaction with no network calls.
- [`wimse`](https://github.com/Ptyktos/wimse): dependency-free Rust library for parsing
  SPIFFE/WIMSE URIs.
- [`ptyktos-agent-runner`](https://github.com/Ptyktos/ptyktos-agent-runner): saga runner
  with a five-phase contract (plan, apply, verify, compensate, destroy).

**[webfold-ai](https://github.com/webfold-ai)**

Web extraction and document conversion. Public pieces:

- [`arxiv-search`](https://github.com/webfold-ai/arxiv-search): arXiv search MCP server
  in Rust.
- [`youtube-transcript-mcp`](https://github.com/webfold-ai/youtube-transcript-mcp):
  YouTube transcript MCP server in Rust.

Much of the rest (the web acquisition engine, benchmarks, the fleet pool and
autoscaler that runs it, and the hosting platform behind Tasmanian Cloud) is private.
